# موقع Zeyad Ekramy — دليل التعديل السريع

## هيكل الملفات

```
index.html        ← هيكل الصفحة الرئيسية (النصوص الثابتة + الأقسام)
admin.html        ← صفحة الأدمن (الهيكل)
config.js         ← إعدادات Supabase
css/style.css     ← تنسيق الموقع (الألوان والأحجام والموبايل)
css/admin.css     ← تنسيق صفحة الأدمن
js/content.js     ← المهارات / الخدمات / رحلتي / ليه تختارني   ⭐ أكتر ملف هتعدل فيه
js/main.js        ← منطق الموقع (تحميل المشاريع، النافذة، الفورم...)
js/admin.js       ← منطق صفحة الأدمن
```

## عايز تغيّر إيه؟

| عايز تغيّر... | روح فين |
|---|---|
| اسمك / الوظيفة / نبذة About / الإيميل / الواتساب / السوشيال / الصورة الشخصية | صفحة الأدمن ← **Site info** (من غير ما تلمس كود) |
| إضافة / تعديل / حذف مشروع | صفحة الأدمن ← **Add project** و **Your projects** |
| مهارة أو مستوى مهارة | `js/content.js` ← `SKILLS` |
| الخدمات | `js/content.js` ← `SERVICES` |
| مراحل رحلتك | `js/content.js` ← `TIMELINE` |
| قسم "ليه تختارني" | `js/content.js` ← `WHY_ME` |
| إخفاء أشرطة المستوى | `js/content.js` ← `SHOW_SKILL_LEVELS = false` |
| الأرقام (10+ / 3+ / 100%) | `index.html` ← ابحث عن `class="stats"` |
| نص الـ Hero (الجملة تحت الاسم) | `index.html` ← ابحث عن `class="lead"` |
| لون الموقع | `css/style.css` ← أول قسم `:root` (`--ac` و `--ac2` و `--pu`) |
| حجم دايرة الصورة | `css/style.css` ← `.av` (`width` و `height`) |
| عدد الضغطات السرية على الاسم | `js/main.js` ← ابحث عن `brandClicks >= 5` |
| إضافة حقل جديد في الأدمن | `js/admin.js` ← القوائم `PROJECT_FIELDS` / `SITE_FIELDS` (ولازم تضيف العمود في Supabase) |

## ملاحظات
- المشاريع والإعدادات بتتحمل من Supabase، فلو غيّرتها من الأدمن مش محتاج ترفع كود جديد.
- بعد أي تعديل على الملفات: ارفعها على GitHub (والمشروع لازم يكون مربوط بـ Vercel عشان ينشر لوحده).
- لما تفتح الموقع محلياً، افتحه عن طريق سيرفر (مثلاً إضافة Live Server في VS Code) مش بالضغط المزدوج على الملف.
